This site documents the **BSE & NSE Corporate Announcements Feed**, an API that returns every corporate filing from India's stock exchanges as structured JSON with PDF links.

- Run it: [apify.com/guiltless_baluster/india-corporate-announcements](https://apify.com/guiltless_baluster/india-corporate-announcements?utm_source=blog&utm_medium=about)
- Code examples: [github.com/lawrekak/india-stock-filings-api](https://github.com/lawrekak/india-stock-filings-api)
